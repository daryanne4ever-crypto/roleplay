# Cambridge Interview Roleplay

Single-page web app for interview practice with:

- 20 Cambridge interview questions in 4 sections.
- Name personalization (captured on question 2 and reused in feedback/prompts).
- Speech synthesis (English voice, prefers male voices when available).
- Speech recognition with silence auto-stop and `Listening...` status.
- Controls: Record, Redo, Repeat, Next, Previous, Finish Interview.
- Dynamic feedback and simple pedagogical scoring.
- Progress bar, question counter, final candidate strength percentage.
- Full Q&A history, per-question feedback/score, and restart flow.

## Run locally

Open `index.html` in a modern browser (Chrome/Edge recommended for Speech Recognition).
