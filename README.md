# Cambridge Interview Roleplay

Single-page web app for B1-B2 interview practice with:

- 20 Cambridge interview questions in 4 sections.
- Name personalization captured on question 2 and reused in following prompts/feedback.
- English TTS for all interviewer prompts and spoken feedback (male-preferred voice when available).
- Speech recognition with silence auto-stop and `Listening...` status.
- Controls: Record, Redo, Repeat, Next, Previous, Finish Interview.
- Dynamic feedback based on short answers, use of `because`, and recognition fallback.
- Progress bar, section indicator, `Question X of 20`, and final candidate strength percentage.
- Full Q&A history, per-question feedback/score, quick review of prior answers, and restart flow.

## Run locally

Open `index.html` in a modern browser (Chrome/Edge recommended for Speech Recognition).
