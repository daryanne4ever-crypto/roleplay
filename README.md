# ING Listening Game

Educational browser game to practice English listening and grammar classification.

## What players do

Players listen to each sentence and classify the target grammar function as:

- Gerund
- Adjective (-ing)
- Continuous Verb
- Infinitive

Sentences also include connectors such as `and`, `but`, and `because`.

## Tech stack

- HTML
- CSS
- JavaScript (no dependencies)

## Run locally

Because this is a static project, you can open `index.html` directly in a browser.

For best behavior with browser speech synthesis, run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
